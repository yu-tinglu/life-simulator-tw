# 人生模擬器（台灣版）

類似 BitLife 的繁體中文人生模擬遊戲，單一 HTML 檔案，手機優先。包含台灣教育與職涯、台股與美股等真實年度報酬、歷史事件、多國家設定、家族傳承與頭像基因系統。

## 遊玩
直接開啟 `game.html`（所有內容已串接為單一檔案）。

## 開發
- 原始碼為 `p*.js`、`p*.html`，依 `build.sh` 的順序串接成 `game.html`。
- `bash build.sh`：建置並檢查語法。
- `bash check.sh [quick]`：重名檢查、建置與迴歸測試（測試檔為 `t*.js`、`sim*.js` 等，需 Node.js）。
- 檔案結構見 `STRUCTURE.md`。新增檔案請放在 `p6.js` 之前，並加入 `build.sh`。

## 資料說明
- 2000–2025 年的市場報酬採公開年度資料，2026 年之後為模擬；學費、利率與薪資為簡化估算，不代表官方統計。
- 遊戲數值與事件效果為遊戲設計的簡化，僅供娛樂。
